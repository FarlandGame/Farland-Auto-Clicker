Farland_autcliker — це настільна програма для Windows, яку створив **Bardiya Alizadeh (Kabir), відомий як Farland_game**. Її визначальна особливість полягає в початку автоматизації: **кожен фізичний клік миші запускає власну односекундну серію додаткових кліків**. Програма призначена для тих, хто хоче власними кліками визначати момент початку серії та незалежно налаштовувати ліву й праву кнопки. Вона поєднує таку поведінку з перським інтерфейсом, налаштовуваним керуванням, збереженими параметрами та готовим до запуску виконуваним файлом Windows.

## Як ваші кліки перетворюються на додаткові кліки

Увімкніть автоклікер, а потім натисніть ліву чи праву кнопку миші. Початковий фізичний клік передається звичайним способом, а програма планує додаткові кліки тієї самої кнопки протягом наступної секунди. Наприклад, якщо ліву сторону встановлено на **20 CPS**, один фізичний лівий клік планує **20 додаткових лівих кліків**. Разом із фізичним кліком ця взаємодія запитує 21 клік загалом; їх обробка залежить від цільової програми.

Другий фізичний клік запускає ще одну серію, навіть якщо перша ще триває. Два такі ліві кліки планують 40 додаткових кліків у межах своїх односекундних інтервалів, які перекриваються. Отже, налаштування описує **кожну окрему серію**, а не загальне обмеження всієї активності, що перекривається. Коли нових фізичних кліків немає, нові серії не створюються; уже заплановані тривають до завершення або до зупинки автоклікера.

## Чим відрізняється цей спосіб роботи

Звичний [режим повторення до зупинки](https://www.opautoclicker.com/) після активації виконує повторювану послідовність. Особливість Farland_autcliker — **серії, що запускаються фізичними кліками**, з окремими налаштуваннями для кожної сторони.

| Взаємодія | Повторення до зупинки | Farland_autcliker |
| --- | --- | --- |
| Почати додаткові кліки | Запустити послідовність повторення | Активувати, а потім фізично клікнути |
| Новий фізичний клік | Не потрібен для продовження повторення | Запускає власну додаткову серію |
| Завершити послідовність | Зупинити послідовність повторення | Кожна серія завершує свій односекундний розклад |

Це порівняння описує два способи роботи; окремі автоклікери можуть мати додаткові режими. Задокументовані переваги Farland — поведінка запуску та незалежне керування.

## Незалежне керування лівою та правою кнопками

Установіть різну частоту для кожної кнопки, від **1 до 10 000 CPS**, та вмикайте кожну сторону окремо. Наприклад, можна налаштувати 20 CPS ліворуч і 8 CPS праворуч: лівий клік запускає серію для лівої кнопки, а правий — незалежну серію для правої. Вимкнення однієї сторони залишає її фізичні кліки у звичайному режимі без створення нових додаткових кліків.

## Керування, яке відповідає вашим потребам

Перемикайте активацію головною кнопкою інтерфейсу або вибраною глобальною гарячою клавішею: середньою кнопкою миші, однією з двох бічних кнопок, F6–F9, Home, End або Insert. **F12** забезпечує аварійну зупинку та закриває програму. Чотири теми — темна, світла, фіолетова й синя — дають змогу вибрати вигляд. Частоти кліків, увімкнені сторони, гаряча клавіша та тема зберігаються для наступного сеансу. Неправильні значення частоти кліків повертаються до попереднього правильного значення.

## Уважна обробка повторюваного вводу

Рушій відрізняє фізичний ввід миші від кліків, інжектованих через Windows, тому власні згенеровані кліки не запускають нові серії. Планувальник керує серіями, що перекриваються, і надсилає кліки з високою частотою невеликими пакетами. **10 000 CPS — це налаштовувана верхня межа, а не гарантія виміряної швидкості**: фактичне передавання залежить від комп'ютера, обробки вводу у Windows та цільової програми.

## Завантаження та знайомство з програмою

Загальнодоступний ZIP для Windows містить виконуваний файл, вихідний код, попередній перегляд інтерфейсу та документацію англійською, японською й перською. Розпакуйте його та відкрийте `Farland-Auto-Clicker/dist/Farland Auto Clicker.exe`; виконуваний файл у пакеті не потребує окремого встановлення Python. Вихідний код призначений для Windows 10 або 11 та Python 3.10 чи новішого й використовує Tkinter і Windows API. Репозиторій також містить шість тестів планування, перекриття сторін, скасування, гарячих клавіш і фільтрації інжектованого вводу; вони використовують імітовані кліки.

## Швидкий початок

1. Завантажте та розпакуйте `Farland_autcliker.zip`.
2. Відкрийте `Farland-Auto-Clicker/dist/Farland Auto Clicker.exe`. Програма в пакеті не потребує окремого встановлення Python.
3. Установіть кількість кліків за секунду (CPS) для лівої й правої сторін та ввімкніть потрібні сторони.
4. Натисніть середню кнопку миші або головну кнопку, щоб активувати автоклікер.
5. Кожен фізичний лівий або правий клік запускає серію додаткових кліків тієї самої кнопки протягом наступної секунди.
6. Натисніть **F12**, щоб зупинити всі очікувані кліки та вийти.

## Керування та налаштування

| Елемент керування | Дія |
| --- | --- |
| Головна кнопка / вибрана гаряча клавіша | Увімкнути або вимкнути автоклікер |
| F12 | Аварійна зупинка та вихід |
| Enter / вихід із поля CPS | Застосувати правильне значення частоти кліків |

Неправильне значення частоти кліків повертається до попереднього. Налаштування зберігаються у `%APPDATA%\Farland Auto Clicker\settings.json`.

## Запуск із вихідного коду

Потрібні **Windows 10 або 11** та **Python 3.10 чи новіший**, включно з Tkinter. Для запуску вихідного коду сторонні пакети не потрібні.

```powershell
py main.py
```

## Збирання виконуваного файлу Windows

Із каталогу проєкту:

```powershell
py -m pip install -r requirements.txt
py create_icon.py
py -m PyInstaller --noconfirm --clean "Farland Auto Clicker.spec"
```

Результат — `dist/Farland Auto Clicker.exe`. Для взаємодії з програмою, запущеною від імені адміністратора, запустіть автоклікер з таким самим рівнем привілеїв; Windows обмежує ввід до програм із вищими привілеями.

## Структура проєкту

| Файл | Призначення |
| --- | --- |
| `main.py` | Інтерфейс Tkinter, керування, теми та посилання автора |
| `click_engine.py` | Хуки вводу Windows та планувальник кліків |
| `settings.py` | Перевірені налаштування з атомарним збереженням JSON |
| `create_icon.py`, `farland.ico` | Значок програми |
| `Farland Auto Clicker.spec` | Конфігурація збирання PyInstaller |
| `test_click_engine.py` | Тести поведінки планувальника й хуків |
| `docs/` | Документація японською та перською |

ZIP випуску містить наявний виконуваний файл Windows та файли вихідного коду. Кеші збирання й тимчасові файли виключено.

## Тести

