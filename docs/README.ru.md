Farland_autcliker — настольное приложение для Windows, созданное **Бардией Ализаде (Кабир), известным как Farland_game**. Его отличительная особенность — способ запуска автоматизации: **каждый физический щелчок мыши запускает собственную односекундную серию дополнительных щелчков**. Приложение рассчитано на пользователей, которые хотят сами определять момент начала серии с помощью мыши и независимо управлять левой и правой кнопками. Этот принцип сочетается с персидским интерфейсом, настраиваемым управлением, сохранением предпочтений и готовым к запуску исполняемым файлом Windows.

## Как ваши щелчки превращаются в дополнительные щелчки

Включите автокликер, затем нажмите левую или правую кнопку мыши. Исходный физический щелчок передаётся обычным образом, а программа планирует дополнительные щелчки той же кнопкой в течение следующей секунды. Например, если для левой стороны установлено **20 CPS**, один физический щелчок левой кнопкой планирует **20 дополнительных левых щелчков**. Вместе с физическим щелчком это запрос на 21 щелчок; результат зависит от обработки ввода целевым приложением.

Второй физический щелчок запускает ещё одну серию, даже если первая ещё выполняется. Два таких левых щелчка планируют 40 дополнительных щелчков в своих перекрывающихся односекундных интервалах. Таким образом, настройка относится к **каждой отдельной серии**, а не задаёт общий предел для всей одновременно выполняемой активности. Если новых физических щелчков нет, новые серии не создаются; уже запланированные продолжаются до завершения или остановки автокликера.

## Чем отличается этот способ работы

Привычный [режим повторения до остановки](https://www.opautoclicker.com/) после включения выполняет повторяющуюся последовательность. Отличие Farland_autcliker — **серии, запускаемые физическим щелчком**, с отдельными настройками для каждой стороны.

| Действие | Повторение до остановки | Farland_autcliker |
| --- | --- | --- |
| Запуск дополнительных щелчков | Запуск повторяющейся последовательности | Включение, затем физический щелчок |
| Новый физический щелчок | Не нужен для продолжения повторения | Запускает собственную дополнительную серию |
| Завершение последовательности | Остановка повторения | Каждая серия завершает своё односекундное расписание |

В таблице сравниваются два способа работы; отдельные автокликеры могут предлагать дополнительные режимы. Подтверждённые особенности Farland — способ запуска серий и независимое управление.

## Независимое управление левой и правой кнопками

Задайте каждой кнопке собственную скорость от **1 до 10 000 CPS** и включайте каждую сторону отдельно. Например, можно установить 20 CPS слева и 8 CPS справа: левый щелчок запускает серию левой кнопкой, а правый — независимую серию правой кнопкой. При отключении одной стороны её физические щелчки продолжают работать обычным образом, не создавая новых дополнительных щелчков.

## Управление под ваши привычки

Переключайте активность главной кнопкой интерфейса или выбранной глобальной горячей клавишей: средней кнопкой мыши, одной из двух боковых кнопок, F6–F9, Home, End или Insert. **F12** выполняет аварийную остановку и закрывает приложение. Можно выбрать одну из четырёх тем: тёмную, светлую, фиолетовую или синюю. Скорости щелчков, включённые стороны, горячая клавиша и тема сохраняются для следующего запуска. При неверном вводе скорости восстанавливается предыдущее допустимое значение.

## Аккуратная обработка повторяющегося ввода

Движок различает физический ввод мыши и щелчки, внедрённые средствами Windows, поэтому сгенерированные им щелчки не запускают новые серии. Планировщик управляет перекрывающимися сериями и отправляет высокочастотные щелчки небольшими пакетами. **10 000 CPS — настраиваемый верхний предел, а не гарантия измеренной скорости**: фактическая доставка зависит от компьютера, обработки ввода Windows и целевого приложения.

## Скачивание и знакомство

Общедоступный ZIP для Windows содержит исполняемый файл, исходный код, изображение интерфейса и документацию на английском, японском и персидском языках. Распакуйте архив и откройте `Farland-Auto-Clicker/dist/Farland Auto Clicker.exe`; готовый исполняемый файл не требует отдельной установки Python. В репозитории также есть шесть тестов для планирования, перекрывающихся серий обеих сторон, отмены, горячих клавиш и фильтрации внедрённого ввода; в них применяются имитированные щелчки.

## Быстрый старт

1. Скачайте и распакуйте `Farland_autcliker.zip`.
2. Откройте `Farland-Auto-Clicker/dist/Farland Auto Clicker.exe`. Готовое приложение не требует отдельной установки Python.
3. Задайте число щелчков в секунду (CPS) для левой и правой кнопок и включите нужные стороны.
4. Нажмите среднюю кнопку мыши или главную кнопку переключения, чтобы включить автокликер.
5. Каждый физический левый или правый щелчок запускает серию дополнительных щелчков той же кнопкой в течение следующей секунды.
6. Нажмите **F12**, чтобы остановить все ожидающие щелчки и выйти.

## Управление и настройки

| Элемент управления | Действие |
| --- | --- |
| Главная кнопка / выбранная горячая клавиша | Включить или выключить автокликер |
| F12 | Аварийная остановка и выход |
| Enter / выход из поля CPS | Применить допустимую скорость щелчков |

Неверное значение скорости заменяется предыдущим. Настройки хранятся в `%APPDATA%\Farland Auto Clicker\settings.json`.

## Запуск из исходного кода

Нужны **Windows 10 или 11** и **Python 3.10 или новее** с Tkinter. Для запуска исходного кода сторонние пакеты не требуются.

```powershell
py main.py
```

## Сборка исполняемого файла Windows

Из каталога проекта:

```powershell
py -m pip install -r requirements.txt
py create_icon.py
py -m PyInstaller --noconfirm --clean "Farland Auto Clicker.spec"
```

Результат — `dist/Farland Auto Clicker.exe`. Для взаимодействия с приложением, запущенным от имени администратора, запускайте автокликер с тем же уровнем прав: Windows ограничивает передачу ввода приложениям с более высокими привилегиями.
